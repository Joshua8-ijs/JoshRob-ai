# 🤖 JoshRob AI

JoshRob AI is an intelligent robotics and navigation platform designed to help users find directions, locate themselves in real time, and receive AI-powered guidance. The project combines modern web technologies, GPS services, interactive maps, emergency assistance, voice interaction, and robotics control into one powerful application.

## 🚀 Features

- 📍 Real-time GPS location tracking
- 🗺 Interactive OpenStreetMap navigation
- 🤖 AI-powered navigation assistant
- 🎤 Voice recognition and voice responses
- 🚨 Emergency SOS system
- 🏥 Nearby hospitals, police stations, hotels, and fuel stations
- 👤 User authentication (Login & Registration)
- 📊 Professional dashboard
- 🤖 Robotics control dashboard
- 🔋 Robot monitoring and status
- 💾 Database integration with Flask and SQLite (upgradeable to MySQL)
- 🌐 Responsive modern user interface

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Python
- Flask
- SQLite / MySQL
- Leaflet.js
- OpenStreetMap
- Git & GitHub

## 🎯 Project Goal

The goal of JoshRob AI is to build an intelligent navigation and robotics platform that helps people who have lost their direction by providing accurate location services, smart navigation assistance, emergency support, and future integration with autonomous robotic systems.
